# 05 — Proposals, Meetings & Weekly Planner — Complete tier

Three page templates, no databases: the words a freelancer sends and
the rhythm that keeps the practice moving.

## A. Proposal page template

Duplicate-this-page template named **Proposal — [Client] — [Project]**:

```
# Proposal for [Client]

## The problem
[One paragraph in the client's own words, from the discovery call.]

## What I'll deliver
- Deliverable 1 — what it is, what it's for
- Deliverable 2 —
- Deliverable 3 —

## Timeline
| Phase | What happens | When |
|-------|--------------|------|
| 1 | | Week 1 |
| 2 | | |
| 3 | Handover | |

## Investment
**Total: $[fee]** — 50% to start, 50% on delivery.
[Or: $X/hour, estimated N hours, capped at $Y.]

## What I need from you
- Access / materials / decisions, with dates.

## Next step
Reply to this page (or the email that linked it) with "go" and I'll
send the first invoice and a start date within one business day.

— [Your name], [your practice] · Valid for 14 days.
```

## C. Weekly planner page

A page named **This Week**, reset every Monday (archive last week's
as `Week of YYYY-MM-DD`):

```
# This Week
## The one outcome that makes this week a win
>
## Client work (max 3)
- [ ]
- [ ]
- [ ]
## Money moves
- [ ] Chase overdue invoices (open the Overdue view)
- [ ] Send follow-ups due (open the Follow up view)
- [ ] Send one proposal or pitch
## Admin (30 min, Friday)
- [ ] Book the week's invoices as Paid where money landed
- [ ] Set next week's follow-up dates in Clients
```
