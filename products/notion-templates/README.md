# Freelancer OS — Notion Template Pack

The product behind the ecosystem's "notion templates for freelancers"
business: a five-template Notion system for solo freelancers who run
their whole practice out of Notion — clients, projects, invoices,
proposals and weekly planning, all linked, no spreadsheets.

## What's in the pack

| # | Template | What it does |
|---|----------|--------------|
| 01 | Freelancer HQ | One home page: today's tasks, active projects, unpaid invoices, pipeline snapshot |
| 02 | Client CRM | Every client, contact, rate and relationship status in one database |
| 03 | Project Tracker | Projects linked to clients and invoices, with a delivery pipeline |
| 04 | Invoice & Income Tracker | Invoices with due-date math, overdue flags and monthly income views |
| 05 | Proposals & Meetings | A reusable proposal page template, meeting notes, and a weekly planner |

Each file in `templates/` is a complete build spec: exact database
properties (names, types, select options), views, formulas, and the
starter content that ships inside the template. Build them in a
Notion workspace following `SETUP.md`, set the HQ page to *Share to
web → Allow duplicate as template*, and that link is the product
buyers receive.

## Honest limits

- This pack is a *template system*, not software: no automations
  beyond Notion's own formulas, buttons and linked views.
- Sample entries in each database are marked `[Sample]` and exist so
  buyers see the system working; the setup guide tells them to delete
  the samples first.
- Prices are USD (Etsy/Gumroad convention). Fees: Etsy ≈ $0.20 per
  listing (4 months) + 6.5% transaction + processing; Gumroad = 10%
  flat per sale. Payout accounts are the owner's to set up.
